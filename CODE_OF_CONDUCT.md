# Code of conduct

Zolt is a friendly little robot, and this is a friendly little project.

**Do:**
- Be kind and patient, especially with people who are new to Swift, macOS or open source
- Give feedback on the work, not the person
- Assume good intent, and ask when something's unclear

**Don't:**
- Harass, insult or demean anyone, for any reason
- Post other people's private information
- Spam, or push people to buy things

If someone breaks these rules, the maintainer may remove comments, lock threads or block accounts.
To report a problem privately, use the contact details on [@c0ldskin's GitHub profile](https://github.com/c0ldskin).
